# Python OOP Mastery: Concepts, Practice & Mini-Projects

## About This Project

This repository documents my structured learning journey through Object-Oriented Programming (OOP) in Python. It focuses on understanding core OOP principles, applying them through progressively challenging exercises, and designing reusable solutions to practical problems.

The project is organized into five practice batches, progressing from fundamental class design to advanced OOP concepts and integrated mini-projects.

Rather than learning syntax alone, the goal is to understand how Python programs can be structured, validated, extended, and maintained using object-oriented design.

## Learning Objectives

- Understand classes, objects, constructors, instance attributes, and methods.
- Distinguish between instance attributes and class attributes.
- Apply encapsulation to protect and validate object data.
- Implement inheritance and method overriding to reuse and extend behavior.
- Use polymorphism to support consistent interfaces across different object types.
- Apply abstraction using abstract base classes and abstract methods.
- Understand composition and relationships between objects.
- Use properties and setters to manage attribute access and validation.
- Implement special methods to customize object behavior.
- Build modular, reusable, and maintainable Python applications.

## Learning Roadmap

### Batch 1: Classes and Objects

**Topics covered**
- Defining classes and creating objects
- Constructors using `__init__()`
- Understanding `self`
- Instance attributes and instance methods
- Initializing and managing object data

**Learning objective:** Build a strong foundation for representing real-world entities using Python classes.

### Batch 2: Attributes and Class Design

**Topics covered**
- Instance attributes versus class attributes
- Class variables and shared state
- Attribute access and modification
- Understanding mutable class attributes
- Designing objects with appropriate responsibilities

**Learning objective:** Understand how object-specific data differs from data shared across instances and avoid common class-design mistakes.

### Batch 3: Advanced OOP Concepts

**Topics covered**
- Encapsulation and controlled attribute access
- Inheritance and code reuse
- Method overriding
- Polymorphism
- Relationships between parent and child classes
- Designing flexible object-oriented solutions

**Learning objective:** Build extensible classes and understand how related objects can share interfaces while implementing different behaviors.

### Batch 4: Advanced OOP and Integrated Practice

**Topics covered**
- Abstraction and abstract base classes
- `ABC` and `@abstractmethod`
- Input validation and exception handling
- Reusable methods and calculated metrics
- Integrating multiple OOP principles
- Designing analytics-reporting systems

**Learning objective:** Combine OOP principles to build reliable applications with clear responsibilities, meaningful validation, and reusable behavior.

### Batch 5: Fresh-Class Practice and Mini-Projects

This batch contains 10 additional practical challenges using new classes and scenarios.

**Projects and exercises covered**

1. Library Management System — private attributes, borrowing, returning, and validation.
2. Employee Payroll System — inheritance, abstract methods, and polymorphic salary calculations.
3. E-Commerce Shopping Cart — composition, product quantities, and total-price calculations.
4. Payment Processing System — abstraction, method overriding, and payment fees.
5. Student Grade Management — properties, setters, class methods, and grading logic.
6. Vehicle Rental System — inheritance, rental calculations, and conditional discounts.
7. Inventory Stock Control — encapsulation, stock validation, inventory valuation, and `__str__()`.
8. Notification System — abstract classes and polymorphic notification methods.
9. Bank Account System — private balances, deposits, withdrawals, and account-specific rules.
10. Online Course Enrollment Platform — inheritance, composition, capacity management, and course enrollment.

**Learning objective:** Apply OOP concepts to practical scenarios and integrate multiple concepts into complete systems.

## Core Techniques Practiced

| Technique | Python concepts |
|---|---|
| Class design | `class`, `__init__()`, `self` |
| State management | Instance and class attributes |
| Encapsulation | Private attributes, properties, setters |
| Inheritance | Parent classes, child classes, method overriding |
| Polymorphism | Shared interfaces and runtime behavior |
| Abstraction | `ABC`, `@abstractmethod` |
| Composition | Objects containing and managing other objects |
| Validation | Conditional checks and `ValueError` |
| Calculated attributes | `@property` and reusable methods |
| Special methods | `__str__()` and object behavior customization |
| Class-level behavior | Class attributes and `@classmethod` |
